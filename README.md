# Cuisine du Cambodge

Site francophone sur la cuisine khmère : recettes, kroeung, poivre de Kampot et mémoire des tables cambodgiennes.

- Domaine : [cuisine-du-cambodge.com](https://www.cuisine-du-cambodge.com)
- Dépôt : [github.com/roro78/cuisine-cambodgienne](https://github.com/roro78/cuisine-cambodgienne)

## Le site

- **Recettes** — amok trey, nom banh chok, lok lak, bai sach chrouk, cari, crabe de Kampot…
- **Saveurs** — kroeung, prahok, poivre de Kampot, sucre de palme, riz Malis
- **Culture** — histoire de la table khmère, repas, influences

Les recettes se consultent, se filtrent, s’enregistrent (favoris) et s’impriment. Les portions se règlent à la volée.
