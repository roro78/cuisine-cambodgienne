À propos

Un carnet culinaire vivant consacré au Cambodge.

Cuisine du Cambodge veut donner envie de cuisiner tout en expliquant ce que les recettes seules racontent mal : les gestes, les produits, les variantes, les territoires et la table autour du plat.

Le point de départ

Ni encyclopédie froide. Ni catalogue SEO. Ni recette prétendument définitive.

Une cuisine familiale et régionale change selon les personnes, les produits disponibles et les habitudes. Le site préfère donner des repères fiables pour comprendre et réussir plutôt que présenter une seule version comme la vérité absolue.

Comment le site travaille

Expliquer ce qui est certain. Nuancer ce qui varie.

Recettes

Une version praticable, pas une version universelle.

Quand un plat connaît de nombreuses variantes, le site l’indique. L’objectif est de proposer un chemin cohérent pour cuisiner et de donner les clés pour l’adapter ensuite.

Produits

Dire quand une adaptation change vraiment le résultat.

Substituer un ingrédient peut être utile. Mais si cette substitution modifie fortement le parfum, la texture ou le rôle du produit, il faut l’expliquer plutôt que faire comme si rien ne changeait.

Sources

Documenter les faits, distinguer les usages.

Les contenus culturels et les produits liés à un territoire s’appuient sur des sources identifiées. Les usages familiaux ou variables sont présentés comme tels.

Photographies

Montrer sans faire tourner les mêmes images partout.

La V16 réduit volontairement la répétition des photos. Une image forte doit avoir un rôle précis ; quand une bonne image manque, une composition éditoriale vaut mieux qu’un visuel hors sujet.

La ligne éditoriale

Ce que le site ne veut pas devenir.

× Une collection de recettes interchangeables écrites pour remplir des mots-clés.

× Un musée figé où toute variante serait considérée comme une erreur.

× Une succession de grandes photos décoratives sans rapport avec ce qui est raconté.
